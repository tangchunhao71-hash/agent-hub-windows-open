# 网盘交付与手动更新

产品版本 0.1.1，Windows 11 x64。安装交付仍为本地待审包；源码公开不等同于安装包通过销售验收。

## 分享目录

使用一个固定网盘目录，最新版、上一稳定版和更新说明分别命名。每次发布使用新版本号和新文件名，保留旧包；不要覆盖同名安装包后沿用旧哈希。当前 0.1.0 也是候选，只能作测试基线，不能标成已验证稳定版。

实际分享地址尚未提供。开发者取得固定 HTTPS 分享地址后，填写 `source/src/release-channel.json` 的 `downloadUrl`，重新构建并检查按钮。`null` 或空字符串隐藏“下载新版”，无占位链接。打开下载目录必须由用户点击，软件不请求版本清单、不自动下载或安装、不校验激活码。发布者不得在 URL 中放账号凭据。

## 本地生成交付包

先冻结干净提交并用 `scripts/build-windows.ps1 -Bundle -Receipt ...` 构建。执行 `scripts/package-netdisk-delivery.ps1 -Receipt <本次收据> -Installer <本次安装器> -OutputDirectory <新的本地交付目录>`。脚本核对提交、构建状态、安装器哈希及版本；只按显式清单复制交付文件，并生成 ZIP、SHA256SUMS.txt 与脱敏 release-manifest.json。失败或未完成验收仍标记 local-review-candidate，不自动批准销售。

## 安装行为

安装器在文件写入及旧版处理前检查真实系统架构、Windows 构建号与客户端类型，只接受 Windows 11 AMD64。使用现有 Agent Bot 注册项识别安装与版本，保留当前用户安装模式。

没有 WebView2 时，在安装器私有临时目录下载微软官方 bootstrapper，执行并核对安装注册结果。失败可重试或打开官方下载页；静默模式失败返回非零且不自动打开网页。重启要求返回 3010。升级也重新检查 WebView2；不通过修改系统设置或卸载共享运行时来模拟缺失环境。

## 验收与销售状态

静态/编译/夹具测试不替代干净 Windows 真机验收。现有 Windows 11 x64 电脑已完成静默安装、0.1.0 到 0.1.1 的覆盖升级及升级前后设置文件/数据库哈希核对；已经安装 WebView2，且测试从打包版 Codex 启动存在用户目录重定向。文件资源管理器双击安装、干净环境缺失运行时补装、完整设置界面回验、卸载和回退仍未完成。

Windows 安装包未签名。许可补充见 RELEASE_LICENSE_SUPPLEMENT.txt；上游品牌图标、应用图标和壁纸的发行使用边界仍需完成审阅。卖家草稿保留于内部 `docs/sales-listing-draft.md`，不放入买家 ZIP。只有实际验收及许可问题关闭、平台类目核定后才对外销售。
