# 安装、升级与卸载

适用：Windows 11 x64。当前为未签名的本地发行候选；尚未在干净机器完成安装、升级和卸载验收。

1. 使用同目录 SHA256SUMS.txt 校验安装器：`Get-FileHash -Algorithm SHA256 <安装器路径>`。
2. 运行用户级 NSIS 安装器，按界面选择安装位置。首次启动无需导入开发者的设置或账号。
3. 系统需要 Microsoft Edge WebView2 Runtime。缺少时安装器尝试下载官方引导程序，因此需要网络；本包不是 WebView2 离线安装包。失败时可重试或打开微软官方下载页，安装 Evergreen Runtime 后重新运行安装器。需重启时先重启，再重新安装。
4. 打开 Agent Bot，在设置中选择要显示的已有客户端。来源没有日志或账号不可用时，相关信息可能为空。账号仍由原客户端管理。

升级前从托盘退出 Agent Bot，保留原安装器及数据目录备份，再运行新安装器。使用同一安装位置，保留应用数据；需要回退时先退出程序，用旧包重新安装，只有在新版本没有不兼容数据迁移的情况下才能恢复旧数据。当前尚无自动更新服务。到固定网盘目录下载带版本号的新包；“关于 → 下载新版”只打开该目录，不检查远端版本。没有真实分享地址时隐藏按钮。

通过 Windows“已安装的应用”卸载 Agent Bot。不要勾选删除应用数据：数据位于 `%LOCALAPPDATA%/app.agentbot.windows`。如需彻底清除，先退出程序并备份，再明确选择清除。不要删除原版 `%LOCALAPPDATA%/app.agenthud.next` 或客户端自身目录。

本版不安装或移除原版 Agent HUD 的客户端回调和 Claude 插件，不自动移除他人设置。卸载不应依赖卸载脚本猜测第三方配置归属。

如果出现 localhost 错误页，该文件不符合本发行版的构建要求；退出并检查版本和哈希。新候选必须使用 custom-protocol 内嵌前端。故障反馈仅提供脱敏错误、系统版本和文件哈希；不要发送 token、完整聊天或账号文件。
