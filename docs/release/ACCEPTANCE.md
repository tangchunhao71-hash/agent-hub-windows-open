# 发行验收边界

本文件用于区分可由源码和构建验证的条件，与必须由实际 Windows 安装验证的条件。未验证不标为通过，实验互派不再作为首发门槛。

| 检查 | 结束条件 |
| --- | --- |
| 产品隔离 | Agent Bot 名称、app.agentbot.windows ID/数据路径一致；不接管旧版 hooks/插件；安装资源只来自显式清单 |
| 构建 | 锁文件一致，相关测试和类型检查通过；正式前端内嵌；收据绑定冻结提交与产物 SHA-256 |
| 导出 | 仅白名单跟踪文件，无 .git、local-only、个人账号、运行数据库；构建/CI 引用文件齐全 |
| 干净安装 | 无 Node/Rust/Bun 的 Windows 11 x64 普通用户可安装、启动、退出、重启、升级、卸载、回退；含中文和空格路径 |
| 核心操作 | 选定来源状态变化、完成卡、正确会话跳转、重启未读恢复/去重、拖动与任务栏避让、两种缩放完成实际操作 |
| 对外发布 | 用户确认公开目标与包范围；云端 CI 如未运行应明确说明；不把签名或商业适用性推断为已完成 |
