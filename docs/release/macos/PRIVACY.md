# 隐私与本地数据

Agent Bot 使用当前用户权限读取已启用来源的本地会话日志、运行状态及账号配额信息。不会要求把登录密码填进 Agent Bot。部分客户端的额度查询会使用其已有登录凭据访问该客户端对应服务；数据是否可用取决于客户端版本、登录与网络。

本地设置、状态缓存和提醒记录位于 Windows 的 `%LOCALAPPDATA%/app.agentbot.windows`，或 Mac 的 `~/Library/Application Support/app.agentbot.macos`，与旧 Agent HUD 分开。程序不会自动导入旧版数据。日志和账号查询可能涉及会话标题、活动信息、用量和账号标识；请在共享设备上按自己的权限使用。安装包和源码导出不包含开发者账号、会话、数据库或截图。此说明不把本地数据隔离表述为对其他同用户进程的安全沙箱。

本版不运行新增云端同步、自动上传诊断或自动更新服务。打开客户端或外部链接由对应应用处理；下载 WebView2 由 Microsoft 安装程序处理。已有第三方客户端的网络行为不受本产品控制。

互相派活默认关闭且不展示入口。只有开发者明确设置 `AGENTBOT_LOCAL_EXPERIMENTS=1` 并提供本机配置后才可能加载实验扩展；它会把明确任务文字交给目标模型服务，因此不属于本说明中的普通状态读取。实验配置、凭据和回执不得随发行包分发。

本版不接管原 Agent HUD 的 hooks 或 Claude 插件。反馈问题前请移除凭据、完整聊天、姓名及本机路径；诊断材料由用户自行审核后决定是否提供。

停止相应来源的读取或退出程序即可停止该次运行的采集。卸载后本产品数据可能保留；需要删除时先备份，再仅清理上述本产品目录。不要删除原客户端的凭据和记录。第三方客户端持有的数据须在相应客户端中管理。本产品没有独立云端账号删除入口，也不承诺代替第三方服务删除数据。
