安装
1. 将 ZIP 完整解压到普通文件夹。
2. 双击 Agent-Bot-0.1.1-windows-x64-setup.exe，按向导安装。
3. 需要 Windows 11 x64（Intel/AMD）。Windows 10、ARM 和 Windows Server 不支持。
4. 缺少 Microsoft WebView2 时会联网补装。失败时可重试，或打开微软官方页面安装 Evergreen Runtime，再重新运行本安装器。
5. 本包尚未签名，Windows 可能显示未知发布者或阻止运行。核对来源和 SHA256SUMS.txt；不要关闭系统安全防护。受设备策略阻止时，请联系设备管理员或等待签名版本。

首次使用
打开 Agent Bot，查看客户端检测提示。你需要自行安装、登录要使用的 AI 客户端，并拥有相应服务权限。检测到安装、配置或日志，不代表登录、套餐有效；未检测到也不一定代表没有安装。
本软件提供已有客户端状态面板、可读取的额度信息、Bot 动效和任务完成提醒。支持程度随客户端版本和本地数据而不同。
互相派活、账号、AI 会员、代登录、激活码、云端授权和自动更新不包含在本版中。

更新
始终从购买时提供的同一个网盘目录取得带版本号的新包。
软件“关于”页会显示当前版本；正式配置分享地址后才显示“下载新版”。它只打开下载目录，不自动判断是否有新版。
更新前从系统托盘退出 Agent Bot，备份数据目录和旧安装包，再运行新安装器，按同一安装位置更新。安装过程中不要勾选删除应用数据。
数据目录：%LOCALAPPDATA%\app.agentbot.windows
回退前退出程序，使用旧安装器。仅在数据格式兼容时恢复对应备份；不要把较新版本数据强行写给不兼容的旧版。

卸载
在 Windows 设置的“已安装的应用”中卸载 Agent Bot。卸载时保留应用数据选项；需要彻底清除时先自行备份。
不要删除 AI 客户端自身目录或旧版 Agent HUD 的数据。
