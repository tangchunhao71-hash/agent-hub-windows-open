# Agent Bot 0.1.1 · 网盘交付候选

- 安装前验证 Windows 11 x64，拒绝 Windows 10、ARM 和 Server；WebView2 缺失时联网补装，失败可重试或打开官方页面。
- “关于”页显示实际版本、本地客户端检测结果及可选固定网盘下载入口；无地址时隐藏入口，未添加自动更新或激活服务。
- 首次启动说明安装、配置、日志的检测结果，不把检测当成登录状态或套餐有效性。
- 保留当前用户安装和数据目录，提供覆盖升级、卸载和回退说明。
- 移除首发不启用的 MCP/Bun 二进制随包资源，实验源码保留；新增来源许可补充和可核对构建收据的网盘打包脚本。
- 仍为待审候选，实际干净 Windows 安装验收与销售许可/平台规则审核未完成。

# Agent Bot 0.1.0 · 发行候选

- 用户确定正式产品名为 Agent Bot，独立应用 ID 与 Windows 数据目录。
- 保留已有一排 Agent、主 Agent 置顶、状态读取、完成提醒与来源跳转。
- Claude 静态原图标与原创橙色圆胖四帧动效分别使用。
- 正式构建默认启用 custom-protocol，release 缺失该 feature 时失败，避免交付 localhost 开发页面。
- 互相派活归为明确启用的本地实验，默认隐藏；不复用一次性真实测试授权。
- 独立发行版不迁移或自动修复旧版客户端 hooks、MCP 注册和 Claude 插件。
- HUD 内容入场动效改用已有 Motion 依赖的简单实现，保留减少动态效果设置；移除 React Bits AnimatedContent 和 GSAP，随安装器保留实际使用的来源声明。
- 安装资源改为显式清单，源码导出补齐构建脚本、DSH 插件和公开说明，排除私人历史及运行文件。

此候选仍需干净 Windows 安装/升级/卸载/回退和原生窗口交互验收。没有公开发布或云端 CI 成功记录。
